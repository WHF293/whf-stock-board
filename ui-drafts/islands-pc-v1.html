主内容区：一页多岛

原整块 main 拆成 页头岛 → 指数摘要岛 → 表格岛 纵排三岛，间隙 10px。表格岛内 toolbar 与表格吸顶逻辑不变（sticky 顶随岛内生效）。岛化收益：指数条 / 表格可按页配独立背景与折叠，页头动作按钮不再挤占表格宽度。

3

详情停靠岛

DockPanel 从贴边通栏改为 独立浮岛：宽 372px（+12px），头部加 📌 固定 按钮支撑多股切换不覆盖；速记等插件扩展区（ctx.stockDetail）落在岛底部 primary-weak 软底卡，与盘口区视觉分层。开合保持现状（openStock 驱动），无路由。

4

实施提示与代价

① 全部改动集中在 MainLayout 的布局层与主题 token，页面组件基本不动；② 暗色 / 三套主题色 / 三套涨跌配色经 CSS 变量自动生效，只需补岛的画布-阴影映射（--shadow-island 暗色加深）；③ 代价：岛间隙吃掉约 20px 横向空间，小窗（<1280px）建议回落为现在的通栏布局。
