侧栏岛（截图圈选 ①）

条目与分组照搬现状：市场行情 / 题材 / 热点资讯 / 自选与账户 / 插件 五组 + 底部速记、设置。岛化点：整栏变独立浮岛（16px 圆角 + 软阴影），组标题右侧保留折叠箭头；激活项按现行 nav-active token（primary-weak 底 + 主色字，若要跟截图的红底可走 data-trend 映射替换）。折叠态仍走 v1 变体 A 的图标小岛。

主内容区（截图圈选 ②）

页头（← 标题 + 插件设置）独立成岛，下方内容按页拆岛：场景 A 拆「概览岛 → 筛选 chips 岛 → ADL 图表岛 → ADR 图表岛 → 底部跑马灯岛」，每张图表可独立滚动/折叠；场景 B 拆「页头岛 → 表格岛」，分页器固定表格岛底部（原贴在窗口最底）。岛间隙 10px 统一露出画布。

3

个股详情停靠岛（截图圈选 ③）

结构照现状：标题行 → 名称/代码 + ＋自选 → 价格区 → 八格元数据 → 周期 tabs（分时/日K/周K/月K/5分/五日）→ 分时图 → 双列五档。岛化点：整面板变 372px 浮岛，与主区脱开；头部保留 ⤢ 放大与 ✕ 关闭；插件扩展区（ctx.stockDetail，如速记）落岛底部软底卡。选中行（tr.sel）与浮岛用同一 primary-weak 语义呼应。

4

与 v1 的差异 & 落地

v1 是通用示意，v2 全部对齐真实页面内容与圈选范围；顶部 headerbar（TitleBar / 浏览器页头）保持现状通栏、不岛化——壳内仅侧栏、主区各岛、详情面板参与岛化。布局改动集中在 MainLayout 的 grid 骨架 + 各页容器拆分，数据逻辑零改动。代价不变：岛间隙占 ~20px 横向空间，<1280px 回落通栏；暗色/三套主题经 CSS 变量自动生效（岛面/画布/阴影各补一条暗色映射）。
