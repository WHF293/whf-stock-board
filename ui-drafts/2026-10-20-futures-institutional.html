基于中金所 CCPM 成交持仓排名每日披露。与全站设计语言对齐：浅灰青画布 + 白卡 12px + 湖青主色 + 红涨绿跌语义 + 无边框弱色分隔。筛选器内置三档合并口径（单合约 / 同品种合并 / 全股指合并）， 直接回答「中信新增多单 5900 手」这类短视频口径的核验需求。

数据源：中金所 sj/ccpm/{yyyymm}/{dd}/{PRODUCT}_1.csv 示例数据：2026-10-19 真实披露（IF） 新增：全股指合并口径 + 醒目口径提示

落地说明

接线方式与数据通道

G1

侧栏分组与路由接线

  1. 侧栏分组：sidebar-group.constants.ts 新增 FUTURES: 'futures'（标题「期货」）， 默认序排在「榜单与资金」之后、「热点资讯」之前（用户可在设置页编排里自由调整组序）。
  2. 菜单与路由：MENU_ITEMS 新增 { path: '/futures/institutional', title: '机构行为', icon: MENU_ICON.FUTURES, group: FUTURES }； router 注册整页路由；MenuIcon 补一个期货图标（如蜡烛图 / 持仓形）。
  3. 页面形态：宿主自带页面（非插件），与板块日历等同级；移动端二期对齐。
  4. 口径切换持久化：品种 / 合并维度 / 交易日 / 选中席位存 settings 或会话内 store，刷新不丢。
G2

数据通道与计算层（全部前端，无后端）

  1. 上游：中金所 http://www.cffex.com.cn/sj/ccpm/{yyyymm}/{dd}/{PRODUCT}_1.csv， 每品种每日一个 CSV（三榜并排，与参考 data/CFFEX_IF_20261019.csv 同构）。编码（GBK/UTF-8）与 URL 规律需开发前冒烟实测。
  2. 通道：走既有 proxy-fetch 体系——浏览器经 /stock-proxy 转发（白名单加 www.cffex.com.cn）， Tauri 走 Rust 直连（capabilities scope 追加同域名）；响应按原始字节透传，按实测编码解码，防乱码。
  3. 解析与计算：utils 纯函数——三榜并集归并（缺失记 NULL 不记 0）→ net_pos / net_chg / 占比 → 行为标签 → 按【交易日+会员】跨合约聚合 → 跨品种聚合（口径 C）。前端计算即可，数据量小（单品种单日 ≤ 60 行）。
  4. 缓存：dataCache 快照（key 含品种+日期），TTL 到次日披露前；时序图按需逐日回拉（默认近 20 交易日）。
  5. 排序：表头点击按 成交量/多单/空单/净持仓/净增减 排序，前端本地排序。
!

常驻风险提示（页面固定区域，不可隐藏）

⚠ 数据局限性（常驻展示）
  1. 所有数据为期货公司代客合并持仓：是席位全部客户总和（公募/私募/量化/散户/套保混合），不是某一家机构的单独头寸。
  2. 中金所只披露达标 / 前 20 会员：未上榜会员与合约无公开数据，分析样本是部分样本。
  3. 净持仓是收盘隔夜快照，看不到盘中 T+0 日内交易。
  4. 空头持仓 ≠ 看空大盘：大量空单是股票现货多头的套保盘。
  5. 净增减 ≠ 多头新开仓：净多变化 = 多头增减 − 空头增减，内部可能同时加多与加空。
  6. 跨品种合并（IF+IC+IH+IM）属不同指数头寸直接相加，逻辑粗糙，仅作口径核验参考。
  7. 本页面仅做资金行为观测工具，所有标签、图表不构成任何投资建议。
