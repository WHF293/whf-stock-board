whf-stock-board · 个股财务报告 · v1

详情整页新增「财务」页签：一次看清营收、利润、家底与现金

以「报告期为轴、四张报表为面」组织个股财务信息：先在详情整页底部页签区新增「财务」入口， 首屏给核心指标卡 + 营收/净利五期趋势图；再往里是财务摘要多期对比表（行 = 指标、列 = 报告期）； 然后是资产负债与现金流关键科目两栏表；最后挂业绩预告（多数股票无披露，空态为一等公民）。 数据全部来自东财 datacenter 四张报表——项目已有取数层 src/common/api/financial.api.ts（2026-09-24 实测四接口全通），本期只做 UI 消费层，不动数据通道。 本期不包含：业务构成（按产品/行业/地区）、最新财务指标卡（F10 报表需显式列字段名，风险另评）、移动端。

v1 · 核心四件套 高保真 UI 稿 PC · 详情整页底部页签 数据源：东财 datacenter（已打通） 不轮询 · 页签触发 + TTL 缓存

StockDetailView 底部页签卡（现有「交易记录 / ETF 持仓股」）追加「财务」页签；停靠面板本期不加，面板保持轻量。

数据 · WHAT

四张报表，零新增接口

财务摘要 / 资产负债 / 现金流 / 业绩预告，四个函数现成且类型齐全；本期新增 UI 组件层与 composable，不改 fetch 通道。

复用：financial.api.ts · 4 个 fetch 函数
节奏 · WHEN

页签触发一次，不轮询

财务数据日级更新，切到页签时拉取一次；结果进 dataCache 快照（TTL 见定论），重复进入秒开；失败按表独立重试。

约束：datacenter 域非行情高频域 · 无封禁先例
DATA · 口径先行

2

指标卡行 · 最新报告期速读

5 张卡取自财务摘要最新一期：营收、归母净利（带同比）、EPS（带扣非）、ROE（带 BPS）、毛利率（带每股经营现金流）。同比为正红 / 负绿，复用 text-up / text-down 语义色，随 data-trend 主题自动换色。卡片头部标注报告期（如「2026 中报」）。

3

趋势图 · 营收 vs 净利（5 期柱状）

ECharts 双系列柱状图，系列色用主色 teal + 蓝灰（不占用涨跌语义色，避免被误读成涨跌）；柱顶标数值（亿元 2 位）；横轴报告期。本期不做折线叠加同比——同比已在摘要表逐期给全，避免图表信息过载。实现走项目 ECharts 注册表（common/components/charts），新增 FinancialTrendChart.vue。

首次进入页签的加载态：指标卡行 + 图表区 + 表格区各出骨架，宽高与最终态一致，避免加载完成跳动。四张报表分别就绪分别点亮（渐进呈现）。

渐进点亮

行 = 指标、列 = 报告期

与东财「财务摘要」同构，方便对照核数。首列指标名吸左、表头吸顶（沿用 table-scroll-sm 既有样式，零新 CSS）。列数自适应实际返回期数：次新股可能只有 1~2 期，不补空列。

2

同比 / 环比上色规则

同比（YSTZ/SJLTZ）为正 text-up 红、为负 text-down 绿、缺失灰「—」；跟随 data-trend 主题。每股经营现金流为负时数值本身也上 down 色提示失血。

3

单位换算

上游金额单位元 → 展示除以 1e8 保留 2 位（新增 utils/format-yi.ts，一函数一文件）；比率、EPS、BPS 原样直出。表头右侧固定「金额单位：亿元」提示，避免误读。

现金流正负色

净额为正 up 红 / 为负 down 绿——这里沿用应用「红涨绿跌」的方向语义而非好坏判断（筹资为正未必是好事），表意是「方向」，与全站一致。

＋

列数对齐

两张表的报告期列统一取财务摘要返回的报告期并集裁剪，保证三表（摘要/资产/现金流）在同一批报告期上竖向对齐，扫读不跳列。某表缺席某期 → 该期整列灰「—」。

MODULE E · 异常态

错误与重试

四张表独立失败独立重试：某张表失败只在其区块内出错误态（保留其它表正常渲染），重试只补拉失败的那张。

1

allSettled + 区块级重试

Promise.allSettled 四表并发，rejected 的表记独立 error 状态；重试函数按表粒度重发。失败文案给上游原始错误摘要（HTTP 码 / 错误名）方便截图排查。

2

不自动重试

与全站约定一致：非行情域但属「上游间歇掐断」场景，失败后手动重试，不做自动重试循环（避免叠加请求触发真限频）。

边界条件

!次新股 / 期数不足：返回期数 < 5 时列数自适应实际数据，不补空列、不报错。
!业绩预告为 null：上游 success=true + result=null 是合法空，UI 出空态不出错误（Module D）。
!单表失败：allSettled 区块级错误态 + 手动重试，不整页报错、不自动重试。
!金融股负债率：60% 阈值对券商/银行常亮，默认按行业豁免提示（行业取财务摘要 BOARD_NAME）。
!非 A 股代码：页签仅对 A 股符号显示（6 位代码均可过 extractSixDigitCode；ETF / 港美股详情不渲染该页签）。
!快照跨报告期陈旧：TTL 内上游新披露一期时快照会落后——TTL 定 6h 且卡片头部展示「数据截至 {最新报告期 + 公告日}」，陈旧可感知而非静默。

定论清单

①落点：详情整页底部页签新增「财务」（StockDetailView），停靠面板本期不加、保持轻量。
②范围：核心四件套（摘要表 / 趋势图 / 资产负债+现金流 / 业绩预告）。业务构成、F10 指标卡不做（F10 报表 fields=ALL 报 9501，需显式列字段名，另行评估）；业绩快报报表不存在，永远不做。
③口径：v1 只做「按报告期」（累计口径，接口直出零换算）；「按年度 / 按单季」需要自算差分与年度归集，留 v2。
④取数节奏：页签切换触发一次、四表并发、不轮询；dataCache 快照 TTL 6h；失败手动重试（区块级）。
⑤语义色：同比 / 净额正负沿用全站 up/down token（红涨绿跌为默认档），随 data-trend 主题自动切换；趋势图系列色用 teal + 蓝灰，不占语义色。
⑥阈值只提示不判断：负债率 60% 弱色底是视觉提示，不是风险口径；金融行业豁免。
⑦无埋点：个人应用，本期不挂任何埋点表。

开发方案（分层落点，全部有现成依赖）

1 · 数据层：零改动复用
